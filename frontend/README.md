# 前端 (Frontend)

基于 Vue 3 + Leaflet 构建 GIS 交互界面。

## 技术栈
- Vue 3 (Composition API)
- Vite (构建工具)
- Leaflet 1.9.4 (地图渲染)
- 高德瓦片服务 (底图)

## 目录结构
```
frontend/
├── src/
│   ├── components/    # Vue 组件 (地图、工具栏、图层面板)
│   └── assets/        # 静态资源 (图标、样式)
└── public/            # 公共静态文件
```

## 启动
```bash
cd frontend && pnpm install && pnpm dev
```
